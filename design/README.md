# Maquettes — application mobile terrain

Maquettes validées des écrans de l'app, produites en Phase II avant le développement.

Générées avec GenSpark AI à partir du brief `Docs/Brief-Maquettes-GenSpark.md` (racine du projet),
en lui laissant le rôle de designer sur la direction visuelle. Direction retenue : **« Fiche technique
éditoriale »** (Fraunces pour les titres, Inter pour l'UI, JetBrains Mono pour les données). **Référence
exacte des tokens, typo et composants : `DESIGN-SYSTEM.md` dans ce dossier — c'est lui qui fait foi
pour l'implémentation, pas le §2 du brief.**

| Fichier | Écran | User Stories | États livrés |
|---|---|---|---|
| `M1 - Connexion.html` | Connexion | US4.1, US4.2 | normal, envoi en cours, erreur |
| `M2 - Mes interventions.html` | Mes interventions | US2.1, US2.11 | données, chargement, liste vide, hors ligne |
| `M3 - Detail intervention.html` | Détail de l'intervention | US2.2, US2.3 | Planifiée, Réalisée |
| `M4 - Completer intervention.html` | Compléter l'intervention | US2.5 à US2.10 | vide/désactivé, rempli/actif, clôturé lecture seule, modale de clôture |

Design system commun web + mobile : `DESIGN-SYSTEM.md` (copie identique côté web, `web/design/`).
Palette et composants identiques entre les deux apps.
